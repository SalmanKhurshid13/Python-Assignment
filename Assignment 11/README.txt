Assignment Objective
----------------------------------------------------
The objective of this assignment is to learn the basics
of image and video processing using the OpenCV library
in Python. Each practical demonstrates a different
OpenCV operation.

----------------------------------------------------
Practicals Completed
----------------------------------------------------
1. Read, Display and Save Image
2. Resize Image
3. Flip Image (Horizontal, Vertical and Both)
4. Draw Shapes and Add Text
5. Image Translation using warpAffine()
6. Image Rotation using getRotationMatrix2D()
7. Binary Thresholding
8. Gaussian Blur and Median Blur
9. Morphological Operations (Top Hat and Black Hat)
10. Canny Edge Detection
11. Read and Write Video File
12. Live Webcam Capture

----------------------------------------------------
How to Run
----------------------------------------------------
1. Install required libraries:
   pip install opencv-python numpy

2. Open the project folder in Visual Studio Code.

3. Run any practical using:
   python Practical_File_Name.py

4. Press any key to close image windows.
   For video and webcam practicals, press 'Q' to exit.
