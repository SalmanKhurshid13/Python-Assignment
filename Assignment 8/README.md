# Flask Registration Form

## Description

This is a simple Flask web application that accepts user registration details.

The application takes:

- Name
- City
- Phone Number

and displays the entered information on a confirmation page.

---

## Technologies Used

- Python
- Flask
- HTML
- CSS

---

## Installation

Install Flask

```bash
pip install flask
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```

---

## Features

- Registration Form
- Flask Routing
- POST Request Handling
- Confirmation Page
